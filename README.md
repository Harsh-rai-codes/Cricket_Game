                                Cricket_Game                           

This is a fun and interactive Cricket Game built using HTML, CSS, and JavaScript. The game allows the user to play against the computer by selecting one of three options: Bat, Ball, or Stump.

Game Rules :
The user selects one option: Bat, Ball, or Stump
The computer randomly selects its option
The result depends on both selections

If User Chooses Bat =
User: Bat | Computer: Ball →  User Wins
User: Bat | Computer: Stump → Computer Wins
User: Bat | Computer: Bat →  Tie

If User Chooses Ball =
User: Ball | Computer: Bat →  Computer Wins
User: Ball | Computer: Stump → User Wins
User: Ball | Computer: Ball →  Tie

If User Chooses Stump =
User: Stump | Computer: Bat →  User Wins
User: Stump | Computer: Ball → Computer Wins
User: Stump | Computer: Stump → Tie

Score Storage Feature :
Your score is automatically saved
Even after refreshing or closing the page, your score remains (stored)
You can continue the game from your previous score
Click the Restart button to reset and start a new score

Features :
Simple and engaging gameplay
Random computer choice for fairness
Instant result display
Clean and responsive design

Tech Stack :
HTML – Structure
CSS – Styling
JavaScript – Game logic

Purpose :
This project helps in understanding JavaScript decision-making, DOM manipulation, and building a basic browser game.
